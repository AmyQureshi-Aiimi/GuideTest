# Subject Access Requests

Locate the files you need across multiple sources for a subject access request. Identify items with PII and PCI with the enrichment tags. Prepare items for disclosure, save for later or assign them to someone else to review or redact.

### What is a Subject Access Request?

A request to a company or organisation asking for the personal information they hold on you. This is a legal right within the UK. It can be requested at any time and is free of charge in most cases.

These requests could be for specific data or more generic information, for example:&#x20;

* Emails between ‘person A’ and ‘person B’ (from 1 June 2018 to 1 Sept 2018)
* Their personnel file
* HR records about the individual
* Interview notes about the individual

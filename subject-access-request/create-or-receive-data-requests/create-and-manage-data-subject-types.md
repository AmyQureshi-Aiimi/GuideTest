# Create and Manage Data Subject Types

Some users can create a data subject type and pre-populate the details that will apply to a data request when it's created. You can set defaults for Searches, Approvers, Cover Letters and Policies.

When you create a new data request and select a Data Subject Type the default settings apply but can be changed.

## Searches&#x20;

Data Subject title - A title for the Subject Data Type&#x20;

Default Sources - Select the sources that should always be used&#x20;

PII Entities - Select the entity types needed&#x20;

Search Terms - Enter search terms that will always be used for this data subject type

***

## Approvers&#x20;

Request Approvers - A requests collection will be shared with them to review if it is ready to be disclosed.&#x20;

Data Owners - Adding a data owner tells anyone assigned to it who is the Subject Matter Expert.

***

## Cover Letter

Cover Letter - Enter a draft cover letter to be used when submitting a response. These messages can be changed and personalised by the assignee before submission.

***

## Policies

Policy Name - The name of the policy or document that will be sent alongside a response.

Policy Details - Anything you need to know about the response their rights and responsibilities.

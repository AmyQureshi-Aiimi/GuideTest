# Assigning a Request

When a data request is submitted via the portal they are not automatically assigned to a user. They will remain in the All SARs area until assigned.

1. Access the SAR application and select All SARs.
2. To find new requests from the portal you apply 2 filters:
   * Created By - Disclosure Portal
   * Status - New
3. Select and open the SAR you wish to assign.&#x20;
4. Select Assign to me.

### Editing a Request

To edit a request it must be assigned to the person making the changes. Once the edits are finished it can be reassigned as necessary.

1. Selecting edit within the SAR.
2. Then go to Collection Settings.
3. Select Owner (Primary Assignee) and search for the user within Find a User.&#x20;
4. Select Next and Save.

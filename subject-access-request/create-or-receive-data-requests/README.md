# Create or Receive Data Requests

Data requests and subject access requests may come via email, telephone or the Disclosure Portal.&#x20;

## Manual Request

If a request comes via email or phone a request will need to be created manually from the SAR application. For help creating a manual SAR application [use our create a manual request guide. ](create-a-manual-request.md)

***

## Requests from the portal

If enabled by an administrator, anyone can submit a request via the Disclosure Portal. [Use our portal guide for support submitting a request from the portal.](create-a-request-from-the-portal.md)

Disclosure Portal URL Example:\
\- For example: [www.TovicciPortal.com/#/verification](http://www.tovicciportal.com/#/verification)\
\- Your administrator will set the Disclosure Portal URL.

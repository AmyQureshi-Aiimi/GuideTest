# Completing a Request

## Disclose Information via Export

When everything is ready and you need to disclose this information to the requestor. You can create a local export to send.&#x20;

### Export your SAR&#x20;

You can export a password protected request folder to your local machine. This means you are able to send the file to the requestor via email or any other system you have. Only information marked as Disclose will be included in your export.&#x20;

1. Select Disclose in the action menu for your options.&#x20;
2. Choose Local Export.&#x20;
3. This will open a pop up with more information.&#x20;
   * You must acknowledge you understand only items marked Disclose will be packaged.&#x20;
4. Enter a Password or select Generate secure password.&#x20;
   * During creation it will show how secure a password is.&#x20;
5. Confirm the password by typing it into the "Confirm Password" box.&#x20;
6. Select Package and Save to export the response.&#x20;
   * This will take you to disclosure details.&#x20;
   * You can see the number and size of files within the disclosure.&#x20;
7. Within About Your Request personalise the cover letter sent alongside the files.&#x20;
8. Select the text box under cover message and type or change anything already within it.
9. Select Save Changes.&#x20;
   * Within About Your Data you can see the policies sent.&#x20;
10. Select Download Package from the action bar to download a zipped folder and PDF to your computer.

## Disclose via the Disclosure Portal

You can export the files to a password protected portal. The portal by default will give the requester 30 days to access the files disclosed. The portal is password protected and the password is sent to their mobile number if available. If not available their password will be emailed to them, please note this is less secure.&#x20;

1. Select Disclose in the action menu for your options.&#x20;
2. Choose Disclosure Portal.&#x20;
   * If information is missing you will have a pop up confirming how the password will be sent.
3. After confirming this or a mobile is available, a pop up with more information will open.&#x20;
   * You must acknowledge you understand only items marked Disclose will be packaged.&#x20;
4. Select Days Until Expiry to change how long the files will be available for.&#x20;
5. Select Export to Portal.&#x20;
   * A password email or text will be sent automatically.&#x20;
6. Select Generate URL Email to create and send this to the requester.

You can find the URL within the Disclosure area under Portal Link.&#x20;

You can delete a response from the portal by selecting Delete Disclosed Response.

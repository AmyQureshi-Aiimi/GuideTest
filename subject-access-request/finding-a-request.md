# Finding a Request

You can see all you open and completed requests in the My SARs area of Aiimi Insight Engine.&#x20;

1. Select SAR from the application menu.&#x20;
2. From here you can see My SARs, All SARs, Analytics and Settings.

### All SARs&#x20;

Access all available requests in one place. You can see what is outstanding and who is working on what. With this you can help others by offering support or sending relevant information you find.&#x20;

{% hint style="info" %}
This view does not include requests which are only available to the owner and contributors.
{% endhint %}

### My SARs&#x20;

Track the progress of your requests in the My SARs tab. Get greater visibility on upcoming deadlines, outstanding reviews and new requests. This will improve visibility of request commitments across the business.&#x20;

Within the My SAR's tab there will be two sections, Owned by me and Contributing to.

Owned by me - Find the requests assigned to you.&#x20;

Contributing to - Find anything others have assigned to you.

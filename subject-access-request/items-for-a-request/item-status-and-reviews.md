# Item Status and Reviews

Data owners, SMEs or other team members may need to review information before it is disclosed.

## Assignees, notes and item statuses&#x20;

&#x20;You can assign an item to another user, add notes to it or update its status within a SAR.

### Individual Items

1. Select the Item Status bar of the item you want to update.
   * This will open the Item Status Model.
2. **Assignee** - Search for and select the user to assign this item to.&#x20;
3. **Note** - You can then add any information to help the assignee complete the assignment.
4. **Disclosure status** - After a review select a status for these items from the list.
5. Select save when you are finished.

### Multiple Items

1. Select the checkbox of each item you want reviewed.
2. Select Update Item Status
   * This will open the Item Status Model.
3. **Assignee** - Search for and select the user to assign this item to.&#x20;
4. **Note** - You can then add any information to help the assignee complete the assignment.
5. **Disclosure status** - After a review select a status for these items from the list.
6. Select save when you are finished.

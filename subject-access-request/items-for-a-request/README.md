# Items for a Request

Once you have created a SAR response you can start to collect the information for it. Others can review the information and help mark anything up for redaction. Redaction helps you send all the relevant information, but ensure they can only see what they should.

<details>

<summary>Payment Card Information (PCI)</summary>

Payment Card Information (PCI) is data related to a card holder, their name, card number or other financial information. Any company that processes or accepts payments will have PCI data. It falls under the data protection regulation under PCI DSS. PCI DSS applies to everyone that stores, processes, or transmits cardholder data.

### There are two main types of PCI data:&#x20;

* Cardholder data - Names, Account Numbers, and Security Codes.
* Sensitive authentication data - PINs, magnetic-stripe data and data stored on a chip.

</details>

<details>

<summary>Personally Identifiable Information (PII)</summary>

Personally identifiable information (PII) is data that could identify an individual from another. It could also identify someone from anonymous data. PII may alone or with other data to identify an individual.

### There are two types of PII data:&#x20;

* Direct identifiers - They can identify a person alone, such as birth certificates.&#x20;
* Quasi-identifiers - Things like race and date of birth that together can identify someone.

### PII may include but is not limited to:&#x20;

* Name&#x20;
* Date of birth&#x20;
* Fingerprints&#x20;
* Address&#x20;
* Telephone number&#x20;
* Drivers license or passport number

</details>



1. From the SAR application and select a SAR to start gathering information for.&#x20;
2. Select Search from the action menu or Start Searching for new SARs.
3. This will run a search based off the information given during creation.

## Add multiple items to a SAR collection&#x20;

1. Hover over an item you want to add and check the select item box.
2. Select any other items you want to add.
   * As you add items you're selected count will increase.
3. Once you have selected everything you need, select Add to Collection.

4. Select the SAR you want to add them to from the list.

***

## Add one file to a SAR Collection

There are two ways to add a single item to a collection.&#x20;

1. Select the checkbox of the files you want to add.&#x20;
2. Select Add to Collection from the bottom of the screen.&#x20;
3. Pick the collection or SAR you want to add it to.&#x20;

Or&#x20;

1. Hover over the files you want to add.&#x20;
2. Select the bookmark at the top of the result panel.&#x20;
3. Pick the collection or SAR you want to add it to.&#x20;

You can add items to a SAR collection from a search in the same way you add things to any other collection.

***

## Importing information for a SAR&#x20;

You can import information for a SAR response. Imported data is added to a SAR response but can not be accessed via any search in Aiimi Insight Engine.

1. Select the SAR you want to add information to.&#x20;
2. Select Import.&#x20;

You can import 1 file at a time with a maximum size of 30MB.

***

## Removing Items from a SAR

1. Select the Item Option menu of the item you want to remove.
2. Select Remove from Collection
   * If the item has been added to the SAR from Aiimi Insight Engine it will be removed from the collection.
   * If the item has been imported to the SAR the item will be removed from the SAR and the system so others can not find it.&#x20;

You can select multiple items from your collection to remove them all at the same time.

# Internal Messaging

Keep communications, files and updates about a request in one place.

1. To send a message or leave a comment to others working on the request, select Messaging from the action menu.&#x20;
2. Go to the Internal tab to send a message to the subject.&#x20;
3. Enter your message in the text box.&#x20;
4. Select Send.

You will be notified of a response and they can be found in the same place.

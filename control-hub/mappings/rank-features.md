# Rank Features

Rank features allow us to store sparse vectors and weights within the index. Rank features store the 'term' being indexed and the corresponding weight, which represents the importance of the term.

## Create a New Rank Feature

Rank features are used for semantic searches underpinned by SPLADE type models.

1. Within the Control Hub go to Mappings > Rank Features.
2. Select Create New Ranks Feature.
3. **ID** - Enter a unique ID for this Rank Feature.
   * This must be in camel case and only contain alphanumeric characters and underscores.
4. **Name** - Enter a user friendly name.
   * This must be alphanumeric characters and underscores only.
5. **Description** - Explain what the rank feature is for.
6. Select Create Rank Feature to finalise.&#x20;

# Enable or Disable a Model

You can enable and disable all the models within a business area at once or control them individually.&#x20;

{% hint style="info" %}
Draft models are disabled and must be published to be used.
{% endhint %}

## By Business Area

1. Select the business area you want to change.
2. Select Enable All or Disable All to change all the statuses.
   * The enable or disable all button will be disabled if the models in this area already match this status.

Changes to the status of a model are automatic you do not need to save anything.&#x20;

***

## Individual Models

1. Find the model you want to enable or disable.
2. Select the toggle for that model to switch its state.

Changes to the status of a model are automatic you do not need to save anything.&#x20;

# Manage Entity Groups

Entities are categorised and live within entity groups. You can add entities to existing groups, edit groups and create new groups.&#x20;

## Create an Entity Group

1. From the entities page in the Control Hub select New Group.
2. **ID** - Enter a unique ID for this group.
3. **Display Name** - Enter a user friendly name for this group.
4. Check which applications within Aiimi Insight Engine can use this group.
   * Search, Manage and SAR.
5. Select Save.

## Edit an Entity Group

1. Find the group you want to edit from the table.
2. Select Edit Group on the group.
3. You can edit any part of the group from the Edit Entity Groups modal.
4. Select Save.

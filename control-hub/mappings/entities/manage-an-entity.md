# Manage an Entity

Entities can be edited, enabled, disabled or deleted.

{% hint style="info" %}
We recommend before you edit, or import an entity you should export a copy as a back up.
{% endhint %}

## Finding your Entities

You can apply filters or search for entities within your entity table to find what you need.&#x20;

* Enter the name within the Entity Name search bar.

Or

* Use the filters to narrow down the list to find what you need.

***

## Enabling and Disabling

You can easily change the status of an entity by using the toggle to enable or disable it.

1. Find the entity you want to change.
2. Select the toggle to enable or disable it.

***

## Edit an Entity

{% hint style="info" %}
We recommend before you edit, or import any entities you export a copy as a back up.
{% endhint %}

1. Find the entity you want to edit.
2. Select Edit on that entity.
   * The Edit Entity Modal will appear.
3. You can change any of the settings as if you were creating a new entity.
4. Select Save.

***

## Exporting entities

{% hint style="info" %}
We recommend before you edit, or import any entities you export a copy as a back up.
{% endhint %}

1. Select Export.
   * This will create and download a json file with all your current entities.
2. Save a copy of this file just in case.

***

## Importing entities

{% hint style="info" %}
We recommend before you edit, or import any entities you export a copy as a back up.
{% endhint %}

You can import multiple entities at a time using a json file.

1. Select Import.
2. Drag the file to upload or select upload a file.
   * Choose the file to upload from your systems file explorer.
3. Choose how to handle new and existing entities.
   * **Add Missing Entities, Skip Existing** - This will add any entities that do not exist and leave all the current entities as they are.&#x20;
   * **Add Missing Entities, Update existing entities** - This will add any entities that do not exist and update all the current entities if there is a change in the file.&#x20;
4. Select Save.

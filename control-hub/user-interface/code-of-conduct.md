# Code of Conduct

Workplace AI gives you the ability to enforce a code of conduct when logging in to Workplace AI for the first time. Should a user reject the code of conduct that user will not be able to use Workplace AI. &#x20;

### Create A Code Of Conduct

1. **Enable Code of Conduct Prompt** - Check this to enable the Code of Conduct for users.
2. Enter your code of conduct message.&#x20;
   * The code of conduct accepts the full range of markdown syntax for formatting.
   * For more information on markdown syntax [see the basic syntax guide on Markdown Guide](https://www.markdownguide.org/basic-syntax/).&#x20;
3. **Preview** - Select preview to see how your message will appear when styling is applied.
4. **Update** - Once you are happy with your message, select update at the top right of the screen.

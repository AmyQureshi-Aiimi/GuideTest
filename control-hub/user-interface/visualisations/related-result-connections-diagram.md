# Related Result Connections Diagram

The network diagram shows insights between large collections of data. It connects the dots between different data sets to show relationships with added meaning.&#x20;

The related results connection diagram shows insights for a large collection of information. Connecting the dots between different information sets and data models for added meaning. You can set upper limits to improve service performance and avoid the network diagram from becoming too crowded. This helps maintain the integrity and usefulness of the network diagram feature for users.&#x20;

### General

1. Within Workplace AI Control Hub&#x20;
2. Go to Global Settings and Visualisations.&#x20;

<figure><img src="../../../.gitbook/assets/image (381).png" alt="" width="563"><figcaption></figcaption></figure>

3. Turn on or off the ability to use the connection diagram by toggling Enable/Disable Visualisation under Connections Diagram.&#x20;

### Data Models

1. Select the Data models to be used in a connection diagram from the Data Models dropdown.

<figure><img src="../../../.gitbook/assets/image (677).png" alt="" width="563"><figcaption></figcaption></figure>

### Promoted Attributes to Display

1. For each data model, choose the attributes from the Promoted Attributes to Display dropdown.
   * Any attributes selected will be available for users to see within the Connection Diagram.

<figure><img src="../../../.gitbook/assets/image (382).png" alt="" width="375"><figcaption></figcaption></figure>

### Performance

_Set upper limits to improve the performance of the connection diagram. This helps keep the diagram usable and helpful for users._&#x20;

1. Enter a Max Request Limit to limit the number of connections requested at once.
   * The lower this number the quicker the diagram will respond. Too low and the connections shown will offer little insight.
2. Enter a Max Diagram Limit to restrict the number of connections shown on a diagram.
   1. The lower the number the less cluttered the diagram will be. Too low and the connections shown will offer little insight.

<figure><img src="../../../.gitbook/assets/image (388).png" alt="" width="563"><figcaption></figcaption></figure>

### Filters

Add filters that narrow down the data that is shown to a user.&#x20;

1. Enter a name for a new group in Filter Group Name.
2. Select the filter from the Filter Property dropdown.
3. Select Add Filter Group.

<figure><img src="../../../.gitbook/assets/image (419).png" alt=""><figcaption></figcaption></figure>

Once you've made all your changes select the overarching control hub Update button.

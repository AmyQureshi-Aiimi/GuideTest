# Application Access

<mark style="background-color:orange;">Needed for initial set up</mark> - [Security Synchronisation](credentials.md) must be completed first.

For each area of the application you can control who has access to what by entering the user groups in the relevant fields. &#x20;

* **Enable New Sources Modal:** Check this to allow users to decide how relevant each source is to them from a modal.&#x20;
* **Default highest access level:** Check this to give all users the highest access level by default.&#x20;
  * If users have a cached access level, that will be used instead.
* **Privileged Access Groups:** Enter the users or groups that can use privileged access within Privileged Access Groups.&#x20;
  * These users will be able to see more then general users.&#x20;
* **Progressive Access Groups:** Enter the users or groups that can use progressive access within Progressive Access Groups.&#x20;
  * These users will be able to see more then general users.&#x20;

<figure><img src="../../.gitbook/assets/image (890).png" alt="" width="563"><figcaption></figcaption></figure>

* **Area Access Fields** - Each area of Aiimi Insight Engine has an access field. Enter the users or groups within the specific field to give them access.&#x20;
  * Only users or groups in each area can access it.&#x20;
* **Toggle Modals Per AD User/Group** - Add users and groups to this field to stop them from seeing Guided Tours, Code of Conduct and New Source Modals.

# Security - General

## General

Define the name and description for this configuration. The description should explain to others what this configuration is for. They will both show on the main configurations page.

1. **Configuration ID:** enter a name for your configuration.
2. **Configuration Description:** Add a description to show the intended use or a settings overview.

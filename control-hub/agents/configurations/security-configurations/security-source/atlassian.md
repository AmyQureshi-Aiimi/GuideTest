# Atlassian

Synchronise users and groups from your Atlassian system into Workplace AI.

1. **Security System:** Select Atlassian from the dropdown.

## General

Add the details for the server including credentials and REST API URL.

1. **Select Credential:** Choose the username and password to connect to Atlassian with from the dropdown.
2. **Atlassian REST API URL:** Enter the Base URL for the Atlassian tenancy to crawl.
   * For example - https://{organisaztion}.atlassian.net/

# Miro Security

Synchronise users and groups from Miro into Workplace AI.

{% hint style="info" %}
The secret-only credential must be configured before you configure the security.
{% endhint %}

1. **Security System:** Select MiroSecurity from the dropdown.
2. **Select Credential:** Select the secret-only credential with a valid OAuth token from the dropdown.
   * This token must be valid for an enterprise team.
3. Continue to the Sync tab and configure the settings for your security source.
   * [How to complete your security sync.](../security-sync.md)

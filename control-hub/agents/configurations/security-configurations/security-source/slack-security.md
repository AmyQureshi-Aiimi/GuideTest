# Slack Security

Synchronise users and groups from your Slack system into Workplace AI.

1. **Security System:** Select Slack Security from the dropdown.

## General

1. Select the Secret Only credential containing the Slack API token.
   * This token is found by installing the Workplace AI connector Slack app.
   * We recommend the authenticated user has admin privileges so it has full visibility of users.

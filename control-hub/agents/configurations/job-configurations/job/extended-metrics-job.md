# Extended Metrics Job

1. Enter the maximum folder depth to be used within Maximum Share Depth. Any folders deeper than this will be ignored.
   * By default this is set to 10,000 which should cover everything for the majority of cases.
2. Enter the scroll size for use for use with these queries.
3. Enter the Source IDs including the metrics operations.
4. Select the Metrics to use when calculating.

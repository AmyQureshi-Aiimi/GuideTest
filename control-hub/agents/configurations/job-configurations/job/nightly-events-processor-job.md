# Nightly Events Processor Job

1. Choose the number of notifications included within a subscribers Nightly Events email.
   * If the number of notifications exceeds this number the email will include a  message of how many additional notifications there are.
   * Check "Is this a Daily Job" to indicate the frequency.
2. Enter the start of the subject for the email. This is normally the system name.
3. Enter the base URL for users to use within the notification email into App URL.

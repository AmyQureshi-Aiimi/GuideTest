# AutomatedSearchJob

1. Check if this a Daily Job if you want to run this everyday.
2. Enter the maximum number of searches to be performed at the same time.
   * Reducing this number would reduce the load on Elastic.
3. Enter the number of milliseconds to wait between searches in the Wait time field.
   * 1000 millisecond = 1 second
   * Increasing this number reduces the load on Elastic.

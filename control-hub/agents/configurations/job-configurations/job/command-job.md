# Command Job

1. Enter the Application File Path of the application to run.
   * This should be something like a .exe, .bat, etc.
2. Enter all of the Command Line Arguments needed to run the application.
3. Enter a working directory to use for the application.
   * By default this will use the Application's containing folder.

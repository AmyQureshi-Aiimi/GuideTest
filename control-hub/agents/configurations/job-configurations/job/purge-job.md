# Purge Job

1. Check Purge old events indices to remove events that are no longer needed.
   * Enter the number of days you would like to store. The purge will not impact events within this date range.
2. Check Purge old exceptions indices to remove exceptions that are no longer needed.
   * Enter the number of days you would like to store. The purge will not impact exceptions within this date range.
3. Check Purge old system event indices to remove events that are no longer needed.
   * Enter the number of days you would like to store. The purge will not impact system event within this date range.
4. Check Purge old system event indices to remove events that are no longer needed.
   * Enter the number of days you would like to store. The purge will not impact system event within this date range.

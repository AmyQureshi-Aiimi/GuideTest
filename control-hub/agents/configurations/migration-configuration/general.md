# General

1. Enter a unique ID in Migration ID.
   * This will appear in the migration card.
2. Enter a name for the Migration into Migration name.
   * This will appear in the migration card.
3. Select the system to migrate from in the Source System dropdown.
4. Select the system to migrate to from the Target System dropdown.
5. Enter the location for the migrated data in Root Location.&#x20;
   * This must be valid in the system source.
6. You can choose to add a description for this into the Migration Description.&#x20;

### Advanced Settings

* Allow Overwrite - If checked this will overwrite any existing documents.&#x20;
  * **Please Note:** proceed with caution as this cannot be undone.
* Include Versions - If ticked all versions of your data and documents will be migrated. If this is unticked only the current file will be migrated.
* Archive Files - This archives your files, it does not copy them from your source.
  * **We recommend talking to your Aiimi contact before ticking this option.**&#x20;
  * Helpful for decommissioning a legacy system.
  * Can only be used when migrating to Aiimi insight Engine.

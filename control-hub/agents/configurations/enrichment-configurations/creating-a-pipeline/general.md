# General

1. **Configuration ID** - Enter an ID for this new enrichment config.
   * This must be lower case and can not include spaces.&#x20;
   * We recommend replacing spaces with underscores.
2. **Configuration Description** - Enter a description for this so others know what it is for.
3. **Indices** - Select one or more indices from the dropdown that will be targeted by the enrichment.

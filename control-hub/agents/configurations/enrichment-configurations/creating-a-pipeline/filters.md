# Filters

1. **File Extensions** - Enter all of the file extensions you want to include.&#x20;
   * Choose if these are part of an allow or a deny list using the check box.&#x20;
   * Do not include the period prefix (i.e. docx and not .docx).
2. **File Size** - Enter a size range (in bytes) for the files that should be included.
3. **Modified Date Ranges** - Select a Modified Date Range to determine the files included.
4. **Entities** - Select the entities that should be used as filters to find items.
5. **Query String** - Enter an Elastic search query string to limit what is processed.
6. **Ready Status** - Item statues to processes.&#x20;
   * For most scenarios 'false' will be fine.
7. **File Actions** - File actions to process (see Manage user guide).
8. **Regenerate Thumbnails** - Check to generate thumbnails for new and updated content.

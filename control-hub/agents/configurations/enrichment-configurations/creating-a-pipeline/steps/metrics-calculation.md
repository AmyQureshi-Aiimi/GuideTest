# Metrics Calculation

This step calculates the visibility of an item. The visibility is how many people within your organisation can see an item based on their permissions. This is typically used for compliance scenarios.

<figure><img src="../../../../../../.gitbook/assets/image (546).png" alt="" width="563"><figcaption></figcaption></figure>

### Advanced Options

1. Select Show Advanced Options
2. Define the maximum number of items to process concurrently in Bounded Capacity.
3. Define the maximum number of items that can be queued.&#x20;

{% hint style="info" %}
Limiting either of these will reduce the memory use but increase the time taken.
{% endhint %}

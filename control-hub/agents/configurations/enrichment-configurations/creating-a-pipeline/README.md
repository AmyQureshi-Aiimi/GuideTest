# Creating a Pipeline

An enrichment pipeline has one or more steps associated with one or more sources.

An enrichment pipeline is used to enhance the data fed into Workplace AI. It can have multiple steps and be associated with one or more source.&#x20;

Enrichment pipeline configurations have 6 tabs that can be customised to suit your needs.

**General -** Basic information about the pipeline.

**Steps -** The specific actions that will be taken for this process.

**Filters -** Limit what is processed during this enrichment.

**Agents -** Where the pipeline will run.

**Schedule -** When and how frequently the pipeline will run.

**Advanced -** Controls around capacity, handling errors, and logging events.

## New enrichment pipeline:

1. Within Control Hub then Configurations
2. Select New Configuration&#x20;
3. Select Enrichment from the menu

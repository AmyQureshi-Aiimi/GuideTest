# Source Configurations

Create a Source configuration to connect your existing sources to Aiimi Insight Engine. You can connect any number of sources to Aiimi Insight Engine.&#x20;

You can customise the source, permissions, files and frequency of crawl. All your data can be enriched and resurfaced in one place.&#x20;

### Google Vault:

We do not have a source connector for Google Vault. But, you are able to create a Job to make the most of this data in Aiimi Insight Engine.

[See our guide for creating a Google Vault Job to connect this to Aiimi Insight Engine.](../job-configurations/job/googlevaultsar.md)

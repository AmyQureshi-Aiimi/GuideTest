# Source Configurations

Create a Source configuration to connect your existing sources to Workplace AI. You can connect any number of sources to Workplace AI.&#x20;

You can customise the source, permissions, files and frequency of crawl. All your data can be enriched and resurfaced in one place.&#x20;

### Google Vault:

We do not have a source connector for Google Vault. But, you are able to create a Job to make the most of this data in Workplace AI.

[See our guide for creating a Google Vault Job to connect this to Workplace AI.](../job-configurations/job/googlevaultsar.md)

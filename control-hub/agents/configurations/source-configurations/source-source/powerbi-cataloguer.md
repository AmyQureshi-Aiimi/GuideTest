# PowerBi Cataloguer

Connect your PowerBi Catalogue to Aiimi Insight Engine to make the most of the data in your business. Once you have selected a Source System type more detail will expand to customise this.

1. Enter the client ID for PowerBI in Application (Client) ID.
2. Enter the URI for Power BI in Application Uri.
   * This is needed to open to open dashboards from Aiimi Insight Engine
3. Select the credential to use from the Select Credential Dropdown.
   * _For support setting up credentials use_ [_our guide on managing credentials._](../../../../security/credentials.md)
4. Enter the URI for the PowerBI API in API URI.
5. Enter the Authentication Uri for PowerBI.
6. Enter the Resource Uri for PowerBI.
7. Enter the Uri to use for redirecting this connection in Redirect Uri.
   * This can be found in the apps authentication in the Azure Portal.

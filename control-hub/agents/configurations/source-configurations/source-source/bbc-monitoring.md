# BBC Monitoring

Connect BBC Monitoring to Aiimi Insight Engine to get media updates that matter to you as they happen.&#x20;

1. **Source System:** Select BBC Monitoring from the dropdown.

## Initial Configuration Steps

1. **Base API URL:** Enter the BBC Monitoring API URL.
   * Set to https://monitoring.bbc.co.uk/api by default.
2. **Select Credential:** Select a BBC monitoring credential from the dropdown.&#x20;
   * _For support setting up credentials use_ [_our guide on managing credentials._](../../../../security/credentials.md)

## Search Configuration

Add multiple searches to your BBC monitoring source to match the information your users need in the Searches tab.

1. **Add More:** Select this to add more searches.
2. **Category:** Enter a name for the search.
3. **Search Text:** Enter the text to search and crawl within BBC monitoring.
4. **Cursor Size:** Enter the cursor size needed.
5. **Days ago to crawl from:** Enter the number of days that should be crawled.

# BIM360

Connect a BIM360 source to Workplace AI to make the most of your data.

1. **Source System:** Select BIM360 from the dropdown.

## Initial Configuration Steps

1. **Select Credential:** Select a Client ID and Secret to use from the dropdown.&#x20;
   * _For support setting up credentials use_ [_our guide on managing credentials._](../../../../security/credentials.md)
2. **Project Root Folders:** Enter the root folder names that should start a crawl.
   * By default Project Files and Project files are included.
3. **Specific Projects to Crawl:** Enter the name of specific projects to crawl.
   * If left blank all projects will be crawled.
4. **Specific Projects to Exclude:** Enter the name of specific projects that should not be crawled.
   * If left blank no projects will be excluded.
5. **Page Limit:** Enter a limit for the items that can be retrieved in a single call.
   * Set to 200 by default.
6. **Wait Period:** Enter a limit in millisecond for the frequency of requests that can be made to this source.
   * Set to 0 (no wait period) by default.

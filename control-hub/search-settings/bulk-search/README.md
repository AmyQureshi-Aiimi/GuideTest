# Bulk Search

Some users do repetitive searches on the same attributes of a data model using various terms. With Bulk Search, users can create a template of searches for any use case. Easily modify the terms in a template and create a new bulk search. Once scheduled, the searches will run automatically and alert a user when new data is found.

Bulk Search streamlines your processes to reduce manual tasks, ensure consistency, and keep you up to date with relevant data.

### Applying permissions

To ensure security bulk searches are run on behalf of the user who set them up. Aiimi Insight Engine applies the users permissions when the bulk search is run. This ensures nobody can see information they shouldn't.

## Finding Bulk Searches

1. Within Aiimi Insight Engine Control Hub select Global Settings.
2. Select Bulk Search.

From here you can turn bulk searches off for all users and see all the current bulk searches set up. You can turn a search on or off and delete them from here.&#x20;

* You may want to turn them off if they are big and will require a lot of resources.

## Enable or Disable Bulk Searches

You can control if users can access bulk searches. If this is turned on it is available to all users.

1. Within Aiimi Insight Engine Control Hub select Global Settings.
2. Select Bulk Search.
3. Select Enable/Disable Bulk Search to turn this feature on or off. &#x20;

# Related Results

### Related Results Table

Set up how results are related and the fields they match on. Each relationship type will show in the related results area with all the items and how they match.&#x20;

1. Enable or Disable related results showing to users by selecting Enable/Disable Related Results.
2. Enter a name for the type of related results under Tab Name.
   * This will be the title for any files that are related within the related results area.
3. Choose the field from the Source Field dropdown to compare.
4. Choose the the field from the Target Field dropdown that will be compared against the Source Field.
5. Choose an order for results to be displayed within the related results area from the Sort By dropdown.&#x20;
6. Select Add New Tab to create a new line and continue steps 2 - 6 until you have added everything you need.

#### Related Results Priority

Once you have created all of the types you need you can choose a priority order. This is the order each type will appear in the related reaults area if there are multiple types.&#x20;

1. &#x20;Use the move configuration up and down buttons to set the order.&#x20;

### Duplicates

You can enable an area in related results to show you any duplicate items. This will show items that are exactly the same as the selected result.&#x20;

{% hint style="info" %}
This will only work for enriched documents as it compares a hash of the document.
{% endhint %}

1. Check Enable Duplicates to see any exact matching items.

### More Like This

You can enable an area in related results to show you similar items. More Like This will show items that are like the current document by querying a set of terms.

1. Check Enable More Like This to see similar items.

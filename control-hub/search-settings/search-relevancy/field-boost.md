# Field Boost

Make it easier for users to find relevant information for them by setting Field Boosts. Create boost rules based on your users needs.

You can set boost rules for specific users, groups or departments based on their needs. Select the fields relevant to them and add a boost value to improve the relevancy of their results. If a specified users search result matches the field selected the boost value is added to the relevancy score.

### **Creating a new field boost**

1. Select New Field Boost.
2. select the data model fields to boost from the Field dropdown.
   * These field will match your data models.
   * Enter a field name in the search bar within the dropdown to search for field or data model.
3. Enter a numerical Boost value.
   * The boost value is added to any other boost values from Makers algorithm.
   * The higher the boost value the more relevant it will appear in the result list.
4. Select a Type that this rule will be used for from the dropdown.
   * Choose between, User, Group, Department.
5. Enter the Username, Department or Group in Type Name.
   * This must match your Active Directory.
6. Use the enter key on your keyboard or the add (+) button.
7. Select Update to apply these changes.

### **Ways to use Field Boost**

You can set these up to match business processes to improve the efficiency of users. The Finance Department regularly need purchase orders and invoices to ensure we and our suppliers are paid on time.

You can boost results that have Purchase Order, Invoice, Supplier data using field boost.

Select the right items from your data models, the boost value they need and the team that needs this boost.

# Minimum Matching Terms Filter

Allow users to refine and filter their results by selecting the number of terms that must be in the results content, filename, or metadata. Words like 'and' 'an' 'or' are not included in the term count.&#x20;

1. Sign in to the Control Hub.&#x20;
2. Go to Global Settings then Search.&#x20;
3. Select Enable Minimum Matching Terms Filter.
   * If the checkbox is marked it is enabled, If it's empty it is disabled.&#x20;
4. Enter a default percentage value for the filter.
   * The percentage can be adjusted within the filters of a search but new searches will default to this value.
5. Select "Update" to save and apply your changes.

# Core Settings

The core search settings that will be used for all searches can be adjusted if necessary. They help used build queries and find relevant results.

1. Sign in to the Control Hub.&#x20;
2. Go to Global Settings then Search.&#x20;

<figure><img src="../../../.gitbook/assets/image (281).png" alt=""><figcaption></figcaption></figure>

### Filename Boost

The Filename Boost is used by Makers Algorithm and applied to a filename that matches the searched terms. By boosting a file with a matching filename the result will appear higher in the relevancy list.

1. Within the Filename Boost field enter a numerical score you want to add to a result with a matching filename.&#x20;
2. Select "Update" to save and apply your changes.

### Default Search Operator

Choose the search operator to use if a user does not define a search operator within a search. By default this will be set to OR.&#x20;

1. Select the Default Search Operator dropdown.
2. Choose the default operator to apply.
   * AND - Use the AND operator to search for multiple keywords.
   * OR - Use an OR operator if you want one or more term returned in a item.
3. Select "Update" to save and apply your changes.

### Query String Query Type

Choose the Query type used, Cross Fields is applied by default. It's recommended to use the Cross Fields which will match across all fields.

1. Select the Query String Query Type dropdown.
2. Choose the Query Type that suits your business needs best.
   * Best Fields, Most Fields, Cross Fields, Phrase, Phrase Prefix
3. Select "Update" to save and apply your changes.

### Match on stemmed text

Pick if results with stemmed text content of the searched terms should be considered an exact match. For example, if a user searched Manufacturing Process, results containing Manufacturing Processes will also appear as exact matches.

1. Check the Allow exact match on stemmed text content to turn this feature on.
2. Select "Update" to save and apply your changes.

# Why My Search Matched

1. Check Enabled to surface to users why a result has appeared in their search result.
2. Enter the user groups of those you want to access this within Feature Groups.&#x20;
   * If this is enabled and no users are specified all users will have access.
3. Check Debug Hits Query Enabled to optimise search.&#x20;
   1. This is for advanced users.
   2. If you enable this you will be returned hits in the browsers console window. &#x20;
4. Enter all the users or groups that should have access to Debugging into Debug Hits Query Feature Users or Groups.

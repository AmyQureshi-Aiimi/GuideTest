# Filename Boost Layer

### Enable a Filename Boost&#x20;

This will boost the "score" of a result using the Filename Boost Layer. This will give an additional "score" to a file which matches the query. Makers algorithm must be enabled to use the Filename boost.

<figure><img src="../../../.gitbook/assets/image (614).png" alt=""><figcaption></figcaption></figure>

1. Go to Search within the Global Settings of Control Hub.
2. Check "Enable 'phrase match' on file name" to turn this feature on.&#x20;
3. Within Boost, enter a score you want to give a result with a matching filename.&#x20;
4. Enter an acceptable Slop percentage if applicable or leave as 0 for exact matches only.&#x20;
5. Click Update to save these changes.

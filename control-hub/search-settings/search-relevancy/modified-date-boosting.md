# Modified Date Boosting

Boost data on the modified date. This will make more recent items appear higher in the search results list. This ensures that when a user executes a search, they are returned the more recently modified documents first. This is used with other algorithms to order the search results.&#x20;

1. For each time period enter an integer value.
   1. The higher the value the larger the boost that will be applied to the result.
   2. Defaults are set for each time period but can be raised or lowered based on importance. &#x20;

# Search Flow Types

There are two top level types of search flows Search Only and Search then Model.

## Search

These appear as Search Focuses in the main application. They work alongside a search performing additional actions like smart filtering and search algorithm selection.

Use these when you just want to modify or simplify the default search behaviour.

***

## Result

Result Flows appear on a result and allow users to select a one or several items and then engage a model.

You can invoke the GenAI panel using the 'Ask a Question' and result options menu.

<figure><img src="../../../.gitbook/assets/image (45).png" alt=""><figcaption><p>Result QA Panel</p></figcaption></figure>

***

## Preview

Similar to result types, preview types appear in the full screen preview component.

### ChatBot (Aiimigo)

You can interact with GenAI via the Aiimigo ChatBot to simplify the experience, collapsing search and model interaction into a single 'Retreival Augmented Generation' RAG step.

Aiimigo ChatBots can perform tool calling to fetch new search results, and interact with other external systems.

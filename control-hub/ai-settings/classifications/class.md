# Class

Classes sit under classifications to make managing your data easier. Classes are shown on results so users can get more detail at a glance. An item can only have one class assigned to it from each classification.

The use cases are endless, they could show risk levels, document types, department ownership, etc.  They are assigned using a set of Class Rules, an AI classification or both.&#x20;

## Managing Classes

### New Class

1. Within the relevant Classification select the Classes tab.
2. Select Add Class.
   * This will open the Add New Label modal.
3. **Class ID:** Enter a unique ID for this class.
4. **Class Name:** Enter a user friendly name for this class.
5. **Class Colour:** Choose a colour for this class. It will be used on a result to identify the class of an item.
6. **Highlighted Entities:** Select any entities that will be displayed on an item with his classification.&#x20;
   * Highlighted entities clearly show key information about an item at a glance. They are visible on a result and within the results details page.
7. Select Add Class.

### Editing a Class

You can edit the details of a class by selecting Edit on that class. This will open up a modal containing the information you can change. Changes made to the class details will be applied to any related items instantly.&#x20;

### Deleting a Class

You can delete a class by selecting Delete on that class. Existing items with this class will have the class removed immediately.&#x20;

### Turn a Class On or Off

You can turn a class on or off any time using the toggle switch on the class.&#x20;

This may be helpful if you're investigating issues or if you're settings up new classes. The class will be turned off but none of the information will be deleted.

Items classified with a turned off class will have the class removed immediately.&#x20;

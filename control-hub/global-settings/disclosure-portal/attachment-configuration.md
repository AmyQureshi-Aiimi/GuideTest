# Attachment Configuration

Attachments can be sent from the Disclosure Portal to the handler of the request. You can configure what can and can not be sent via the portal.

1. **Max Attachment Size (MB) -** Enter the Maximum Attachment Size that can be sent at once.
   * This is for the total files sent in not per file.
2. **Max number of Attachments -** Enter the Maximum Number of Attachments that can be sent at once.
3. **Allowed File Extensions -** Enter the extensions that are allowed to be sent via the portal.&#x20;
   * Type each file extension and select the edit (pencil icon) to change them.
   * You can delete an extension by selecting the delete (trash can icon).

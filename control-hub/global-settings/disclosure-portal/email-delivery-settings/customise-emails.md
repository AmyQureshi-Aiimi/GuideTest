# Customise Emails

There are a number of emails that can be customised with your own messaging. All messages can be written using HTML markup too.&#x20;

### Customisable Emails

**Link Email** - The email sent to a data request with a link to the Disclosure Portal

**Password Email** - Email containing the password for the Disclosure Portal.

**Publish Email** - Informing the contact that the data has been published to the Disclosure Portal.

**Message Received Email** - Let the contact know a message has been sent to them through the privacy portal.

**Disclosure Delete Email** - Tell the contact when and if a disclosure has been deleted.&#x20;

**Portal Deleted Email** - Tell the contact the Disclosure Portal has been deleted and they will no longer have access.

### Customising the Emails

1. Enter the Subject for the email within the Subject.&#x20;
   * This clearly tell the recipient what to expect from the email.
2. Enter all of the text for the body of an email within the Email Content text box.
   * This can be personalised using HTML markup.

There are a number of placeholder values that can be used to populate data.

**\~REFERENCE\~** The Unique ID of the disclosure portal.

**\~NAME\~** The name of the collection for the Disclosure Portal.

**\~SUBJECT\~** The configured name of the Subject.

**\~DATE\~** The expiry date of the disclosure portal DD/MM/YYYY.

**\~FROM\_NOW\~** The number of days until the expiry date when the email is sent.

**\~REPLY\_EMAIL\~** The email specified in the Brand Settings tab.

**\~DISCLOSURE\_URL\~** The public URL for the disclosure portal, can be used in combination with the reference to create the disclosure URL.

**\~PASSWORD\~** The password will only appear in the password email. In any other email this placeholder will be ignored.

3. Once you have entered the copy of the email you can select Preview Email. This will show you how the email will appear for the recipient.&#x20;

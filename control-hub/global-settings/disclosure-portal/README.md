# Disclosure Portal

If you are using our platform for compliance scenarios you may want to disclose data and documents to users with our disclosure portal. This provides a secure means to transmit data, messages and documents.

The disclosure portal allows users to securely disclose a SAR to the requestor. Users can also message the Requestor of a SAR to clarify information or provide documentation.

### Disclosing To The Portal

User can export the SAR disclosure files to a password protected portal. The portal by default will give the requester 30 days to access the files disclosed. It is password protected and the password is sent to their mobile number if available. If a mobile number is not available their password will be sent via email, please note this is less secure.&#x20;

### 2-Way Messaging

SAR users can keep all their SAR work in one place. 2-way messaging gives SAR requestors and owners a way to message and share files via the Disclosure Portal. Keeping communications, files and updates about a SAR in one place.&#x20;

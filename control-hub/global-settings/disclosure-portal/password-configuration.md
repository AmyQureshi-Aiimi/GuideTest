# Password Configuration

You can choose the rules for the passwords that are configured for accessing the Disclosure Portal.

1. **Included Non-Alphanumeric Characters -** If checked, symbols will be used within passwords (&, @, \*).
2. **Minimum Password Length -** Enter the minimum number of characters that should make a password.
   * The cannot be less than 10. We recommend a minimum of 12.&#x20;
3. **Maximum Password Length -** Enter the maximum number of characters that should make a password.
   * This cannot be more than 20.
4. **Reset Password Link Expiry (minutes) -** Enter the number of minutes password reset links are valid for.&#x20;

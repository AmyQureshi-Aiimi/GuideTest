# Disclosure Portal Set Up

There are a few settings required to allow disclosures to the portal and requests to come from the portal.



1. **Enable disclosures to the portal -** If enabled disclosures can be made via the Disclosure Portal.&#x20;
2. **Disclosure Portal Public URL -** Enter the URL that anyone will use to access the portal.
3. **Disclosure Portal Admin URL -** Enter the Admin URL.
   * This allows the Search application to manage requests.
4. **Default Disclosure Expiry -** In days, enter when a disclosure should expire.
   * This date can be adjusted as needed by users within the SAR application.
5. **Maximum Disclosure Expiry -** In days, the absolute maximum number of days before a disclosure is expired.

# Requestor Message Limit

Messages can be sent from the Disclousre Portal by the requestor to the handler of the request. You can configure the number of messages that can be sent in a time period.&#x20;

1. **Number of Messages -** Enter the maximum Number of messages that can be sent in the time limit.
2. **Time Window in Minutes -** Enter the Time Window in minutes to determine the time limitation for the messages.&#x20;

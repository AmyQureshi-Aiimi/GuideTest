# SAR Disclosure Document Storage

## SAR Disclosure Settings

1. **Enable merged item exports -** If checked, items can be merged into a single PDF result.
2. **Merged File Size Limit -** Enter the maximum size a merged file can be.&#x20;
   * If the merged files goes over this it will create multiple merged files.

### SAR Disclosed Document Storage

1. **Enable storage of disclosed data for SAR collections -** If checked, items disclosed will can be stored in a specific source.
2. **Storage Source -** Select a source from the dropdown.
3. **Storage Source Root -** Enter the location where the items should be stored.

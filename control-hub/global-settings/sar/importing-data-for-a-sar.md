# Importing Data For A SAR

## SAR Import

1. **Enable File Import on SAR Collection -** If checked files can be imported to a SAR Collection from external sources.
2. **Enable Disclosure Portal Attachments -** If checked attachments received from a SAR requestor via the portal can be imported.
3. **Enable SAR Lifecycle Archiving** - If checked SARs can be configured to archive certain information after a set period of time.
   * This requires a SAR Archiving job to be configured. [For help creating a Job see our SAR Archiving Job Guide.](../../agents/configurations/job-configurations/job/sar-archiving.md)
   * Users with SAR Configuration Access are able to edit the lifecycle settings. [For help managing users access to this see our guide on SAR Access.](sar-configuration-access.md)
4. **Destination Source -** Select the Destination Source from the dropdown list.&#x20;
   * Choose from a FileSystem,  Document Store or SharePoint.
5. **Destination Source Root -** Enter the Destination Source Root you want to use for imported files.

# SAR File Status

Take control of the statuses available for items within a SAR. You can create new statuses, rearrange the order and edit and delete existing statuses.

## Add a new status

Enter the details for a new status in the form on the right.

1. **Unique ID (Mandatory):** Enter a Unique ID for this status using lowercase letters only.
2. **Label (Mandatory): Enter a user friendly name for this status.**
   * This is the name that will be shown to users.
3. **Description (Mandatory):** Enter a description to show with this status when reviewing items.
4. **Confirmation Text:** Enter any text that should be shown when confirming this statuses selection.
5. **Is Default Status?:** If checked, items without an explicitly applied status will be given this status.
6. **Is disclosable Status?:** Check this to include the status on a document when it is disclosed.
7. Select Save
8. The new status will appear in the table on the left and you can rearrange it as you need.

## Rearrange statuses

You can change the order that these statuses appear to users in.&#x20;

1. Drag and drop the statuses in to the order you want within the table.

<figure><img src="../../../.gitbook/assets/image (852).png" alt="" width="375"><figcaption></figcaption></figure>

## Edit a status

1. Select the status from the left hand table.
2. Edit the details of this status in the right hand form.
   * Unique ID, Label, Description, Confirmation Text, Default Status, Disclosable Status.
3. Select Save when you have finished editing the status.

## Delete a status

1. Find the status you want to delete from status table on the left.
2. Select the Delete icon for the status.
3. Save your changes by selecting Update at the top of the page.
   * This action cannot be undone.

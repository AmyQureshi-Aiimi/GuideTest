# Metrics

By configuring a commandJob, Workplace AI will pre define 6 KPI metrics. These can be viewed by end users in a Metrics dashboard. In order to provide extra context, administrators can add targets for each KPI that will appear on the dashboard.&#x20;

## Access

1. **Usage & Behaviour** - Enter the usernames or groups of those who should have access.&#x20;
2. **KPIs** - Enter the usernames or groups of those who should have access.&#x20;

***

## Key Performance Indicator Working Hours

Select the working hours so you can ensure the KPI calculations are accurate.&#x20;

1. **Start Time** - Select the normal Start Time for the day from the dropdown.&#x20;
2. **End Time** - Select the normal End Time for the day from the dropdown
3. **Exclude Weekends** - You can include or exclude weekends if you don't work weekends.&#x20;

## Key Performance Indicator Targets

KPI targets can be added individually or in bulk through a CSV.&#x20;

### Add An Individual Target

1. Select Add Target.
2. Provide values for each of the KPI’s, these will become the target for that KPI.&#x20;
3. Once complete, click Save Changes button in the top right corner of the page.

<figure><img src="../../.gitbook/assets/image (501).png" alt=""><figcaption></figcaption></figure>

### Add Bulk Targets

1. Select Add Bulk Targets.
2. Drag and drop a CSV file with these targets or select the upload field to find the file in your explorer.
3. Select Import to process this file.&#x20;

### Delete Targets

1. Select the checkbox to the left of the metrics
2. Select Delete (X) Targets to remove multiple at once.

Or

1. Select the Delete (Trash can icon) to the right of the table to remove an individual row.

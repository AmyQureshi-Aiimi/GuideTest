# App Settings

Configure the navigation for your Logo and the Search page button. You can customise the URL for each of these.&#x20;

## General

{% hint style="info" %}
The frontend URL must be enabled to allow users to share items.
{% endhint %}

* Set the Frontend URL to the external facing URL if:&#x20;
  * You are hosting from behind a load balancer or web application firewall.
  * The DNS/URL is different from the actual server addresses.

## Header Navigation

* Choose where clicking on the URL will take you. Enter the Logo URL, by default this will take you to the landing page.&#x20;
* Choose where clicking Search from the menu will take you. Enter the Search URL, by default this will take you to the landing page.&#x20;

# Collections

When users perform a search and find information they need, they can group them in a collection. By grouping data as you go, users can come back to it any time. Collections won't create duplicates, but give users a way to access their data quickly.&#x20;

1. **Enable exporting of the manifest** - Check this to allow users to export the collection manifest.
2. **Collection Export Limit (Bytes**) - Set the maximum size of a collection that can be exported in bytes.
   * By default this is set to 500MB or 524,288,000 bytes.
3. F**ile Import Size Limit (Bytes)** - Set the maximum size of file imported into a collection in bytes.
   * By default this is set to 30GB or 31,457,280 byes.

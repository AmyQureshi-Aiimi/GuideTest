# Classifications

Classifications sit under classification schemas to make managing your data easier. Classifications are shown on results so users can get more detail at a glance. An item can only have one classification assigned to it from each schema. They are assigned using a set of Class Rules, an AI classification or both.&#x20;

The use cases are endless, they could show risk levels, document types, department ownership, etc. &#x20;

## New Classification

1. Within AI Studio select Classification from the menu.
2. Select the schema from the list that you want to add a classification for.
3. Select Create and Classification from the dropdown.
   * This will open a Create New Class modal.
4. **Classification Name:** Enter a user friendly name for this classification.
5. **Classification ID:** Enter a unique ID for this class.
6. **Classification Colour:** Choose a colour for this class.&#x20;
   * It will be used on a result to identify the class of an item.
7. Select Create Classification.

## Editing a Class

You can edit the details of a classification by selecting Edit on that classification. This will open up a modal containing the information you can change. Changes made to the classification details will be applied to any related items instantly.&#x20;

***

## Deleting a Class

You can delete a classification by selecting Delete on it. Existing items with this classification will have it removed immediately.&#x20;

***

## Turn a Class On or Off

You can turn a classification on or off any time using the toggle switch on the classification.&#x20;

This may be helpful if you're investigating issues or if you're settings up new classes. The class will be turned off but none of the information will be deleted.

Items classified with a turned off classification will have it removed immediately.&#x20;

***

## Classification Folders

Under a schema you can group your classifications into groups using folder. New folders must not be empty so when you create a new one you will also need to create a Classification to go within it.&#x20;

1. Select Create and Classification Folder from the dropdown.
2. This will open a Create New Folder modal.
3. **Folder Name** - Enter a name for the folder.
4. Select Create
   * This will open the new classification modal for you to add a classification.

To delete a folder select Actions and Delete Folder from the dropdown.

# Notification Settings

## Collections

### Default Collections Alerts

Choose how you receive notifications and what you receive them about.

* **Live notifications** - Check this to receive on screen notifications while you are within Workplace AI.
* **Email notifications** - Check this to receive notifications via email.
* **Notify me when** - Check the events you will be notified about from the list.

### Custom Alerts

Create a custom alert to receive notifications when items within a collection change.

1. Select New Alert
2. **Collection** - Select a collection from the dropdown.
3. **Priority** - Select the priority of the notification.
   * Low, Medium, High.
4. Select Save.

***

## Records

Create custom alerts to tell you when an items labels anywhere in the system change.&#x20;

1. Select New Alert
2. **Record Type** - Select the type of record you want to be alerted about.
3. **Labels** - Select the labels you want to keep an eye on from the dropdown.
4. **Record** - Start typing to search for a specific item to monitor.&#x20;
5. **Priority** - Select the priority of the notification.
   * Low, Medium, High.
6. Select Create.

***

## Saved Searches

If you have any saved searches configured you can customise the notifications you receive for it.&#x20;

1. Select New Alert
2. **Saved Search** - Select the saved search you want alerts for from the dropdown.
3. **Notifications options** - Select when you would like alerts.
   1. Notify me when results are created.
   2. Notify me when results are created and existing results are modified.
4. **Priority** - Select the priority of the notification.
   * Low, Medium, High.
5. Select Create Alert.

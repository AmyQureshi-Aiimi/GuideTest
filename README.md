# Introducing Workplace AI

Imagine using one app to find all the information you need to do your job, information you didn’t know existed and you didn’t know you wanted. Workplace AI is a Search Engine that gives you access to information when you need it. Workplace AI has four layers that work together to create a searchable data universe. It's secure and full of valuable new insights.

### Discovery&#x20;

Layer 1 - Workplace AI goes through every repository, to create a catalogue of everything in your organisation. It looks for file names, properties, where it's stored and who can access it.

### Enrichment&#x20;

Layer 2 - It uses machine learning to add value to your data. Automatic entity recognition, text extractions, geotagging and classifications.

### Repository&#x20;

Layer 3 - It then brings information back to you showing you the information you didn't know you needed. It stores millions of pieces of information, security configurations, enrichment and configuration data.

### Gateway&#x20;

Layer 4 - The bouncer at the door. It makes sure the information is secure, correct access and corporate security protocols are applied. This includes any multi-factor authentication and single sign-ons.

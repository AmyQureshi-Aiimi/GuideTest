# User Security

There are a few ways you can control your user security. You can determine who has access, how they authenticate themselves and apply a code of conduct for using the system.

## User Authentication

Before getting access to the app or its content, users need to be authenticated. Authentication is the process of proving you are who you say you are.

Workplace AI provides two ways for users to authenticate:​

1. Login using a username and password.
2. Single sign-on (SSO).​

As part of authentication we store the groups that a user is a member of.​ These groups can be used to control what users can access.

***

## Code of Conduct

You can configure a code of conduct that users must accept before using the system. Whenever the code of conduct is updated, users must re-accept it before they can use the system.

For more information [see our guide on the Code of Conduct](../../control-hub/user-interface/code-of-conduct.md).

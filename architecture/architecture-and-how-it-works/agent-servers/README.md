# Agent Servers

Agent servers run the various Aiimi Insight Engine services. They make up the ‘backend’ of the platform and can be Windows or Linux Services.&#x20;

### Recommendations

* For a small setup, all agent servers may run on the same server.&#x20;
* For scaled larger or more complex platforms different agents should run on different servers.

{% hint style="success" %}
If you are unsure what is best for your organisation your contact at Aiimi will be able to help.

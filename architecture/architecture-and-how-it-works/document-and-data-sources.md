# Document and Data Sources

The source agent connects to the data and document sources. These systems contain the data and documents that you want to ingest into Workplace AI.&#x20;

These are configured using the control hub. We have a range of source connectors and are working to add more. Customers, partners and Aiimi can build customer specific ones if required.

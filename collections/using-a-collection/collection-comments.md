# Collection Comments

You can add comments to a collection for others information or to remind yourself in the future. Exported collections will not have these comments, but will stay in Aiimi Insight Engine.

## Adding

1. Open the collection you would like to comment on.
2. Select Comments.

![](<../../.gitbook/assets/image (212).png>)

3. Enter your comment into the text box.
4. Select submit.
   * Comments are visible to anyone with access to the collection.

<figure><img src="../../.gitbook/assets/image (215).png" alt="" width="355"><figcaption></figcaption></figure>

***

## Edit or Delete

1. Select the three dots of the comment you want to change.
2. Select Edit or Delete.

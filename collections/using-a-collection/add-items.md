# Add Items

After you've found the result you are looking for there are 2 simple ways to add it to a collection, from the results list or a result details view.

## Result List

From your results list you can add 1 or multiple results to a collection. You can add them to an existing collection or create a new one.

1. Hover over an item to show your quick actions menu.
   * _When you tab into a result card the actions menu will also become available._
2. Select Add to Collection (bookmark) in the quick bar.&#x20;
   1. Or you can select the Option menu at the end of this list.
   2. Select Add To Collection from the dropdown list.

Or

1. Select all the items you want to add.&#x20;
2. Once you have selected everything you need select Add to Collection.

<figure><img src="../../.gitbook/assets/image (240).png" alt="" width="375"><figcaption></figcaption></figure>

Then

3. Select the collection type you want to add it to.
   * _This will open the Collection pop up._
4. _Then you_ can add an item to an existing collection or create a new one from here.

***

## Result Details

1. Open the details page of the result.&#x20;
2. Select Add to Collection.&#x20;
3. From the list, select the collection type to add it to.
   * This will open a new modal.
4. You can add an item to an existing collection or create a new one from this modal.

![](<../../.gitbook/assets/image (120).png>)

***

## Import Items

When gathering information for a collection some crucial information may not be available in Aiimi Insight Engine. This could be information stored on other sources or paper documents for example.

For certain collection types you will still be able to add these items to a collection.

1. Go to the collection you want to add the item to.
2. Select Actions.
3. Choose Import from the dropdown menu.
   * This will open an import files modal.
4. Drag and drop the file you want to add or select Upload a file to open your computers folder browser.
   * You can only upload one file at a time. The file must be 30MB or less.
5. Select Upload.

<figure><img src="../../.gitbook/assets/image (15).png" alt="" width="375"><figcaption></figcaption></figure>

When an item is uploaded to a collection it won't be found within the search application. It will go through some enrichment steps like the other items in Aiimi Insight Engine. This will allow you to preview it and perform a search within the item.&#x20;

# Sharing a Collection

Sharing a collection with others allows them to View, add and make comments on the collection.&#x20;

## From The Collection Hub

### Sharing

1. Select Share Collection from the collection.
2. Start typing the name of a user in Share with.
3. Select the user from the list.
4. Choose the access level for the user by checking the relevant boxes.
   * User can edit the collection&#x20;
   * User can delete the collection&#x20;
   * User can redact items in the collection
5. Select Share.

<figure><img src="../../.gitbook/assets/image (208).png" alt="" width="375"><figcaption></figcaption></figure>

### Editing

1. Open the collection you would like to change.
2. Select Sharing Settings.
3. Under shared with, select Edit next to the user you want to change.&#x20;
4. Change the access level from the list.
   * No Access will remove the user from the collection completely.
5. Select Save.

# Kashmiri Release

## Simplifying SAR Data Management

SAR Lifecycles are a reliable, low-maintenance way to simplify SAR data management. They ensure the information you gather is only kept for as long as it's needed. \
The lifecycles can be aligned with any internal controls and ICO regulations. Once set, collected items will be removed or deleted after the set time.

***

## A Cleaner And Faster Manage Experience

These updates to manage reduce mental load, simplify document triaging and speed up decision making.&#x20;

* The result list now includes thumbnails, file sizes and locations.&#x20;
* Key actions like ‘Review’ and ‘Assign user’ have moved to the quick actions menu.&#x20;
* The entity labels shown are limited to 3 so you can see more results per page. The additional entities can be found in the dropdown when you need them.
* You don't need to keep adjusting the page as it now remembers if the filters and histograms were open or closed.

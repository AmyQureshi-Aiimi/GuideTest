# Using AI Enrichment Steps

This will guide you through configuring AI Enrichment Steps into your enrichment pipelines.

1. Start configuring an enrichment step within the Control Hub.
   * [See our enrichment configuration guide for help starting.](../../../control-hub/agents/configurations/enrichment-configurations/creating-a-pipeline/)
2. Within Steps, add the AI enrichment step using the Add (+) button.
3. Select the step in the process list.
4. From the dropdown select the agent server running the AI Enrichment Service.
5. Add any additional steps to execute.&#x20;
   * Depending on the step selected, you may be need additional parameters. [Further information on adding other enrichment steps.](../../../control-hub/agents/configurations/enrichment-configurations/creating-a-pipeline/steps/)

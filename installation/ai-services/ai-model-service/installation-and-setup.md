# Installation and Setup

This guide assumes you are familiar with Python and JSON config files. It also assumes that you have worked through the prerequisite sections.

This section shows you how to run the service from the command line, which is useful for testing. It also shows you how to run it as a service, which is best suited to a production environment.

The AI Model Service should be found in the InsightMaker.Python folder that you created in the prerequisites step.

## From The Command Line

{% hint style="info" %}
We recommend you get the service running from the command line first so you can easily spot and resolve issues.
{% endhint %}

### Activate Python Virtual Machine

1. Activate your virtual environment by navigating to the AIModelService/venv/Scripts folder and running: `activate.bat`
   * You should now see (venv) at the start of your command line.
2. On the command line navigate back to InsightMaker.Python\AIModelService

### Python Torch run-time prerequisites.

**For Windows -** Visual Studio runtime must be installed. [https://visualstudio.microsoft.com/visual-cpp-build-tools/](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

**Other Operating Systems** - Check requirements [https://pypi.org/project/torch/](https://pypi.org/project/torch/)

### Install Requirements

1. Use ‘pip’ to install all the requirements in the latest requirements file:
   * **Online:** `pip install -r requirements_3.12.8.txt`
   * **Offline** (From an internet connected machine):
     1. Create a temporary folder.
     2. Navigate to the temporary folder.
     3. `pip download -r requirements_3.12.8.txt`
     4. Copy the resulting contents of the temporary folder to the target server.
     5. Run the following command on the target server: `pip install --no-index --find-links C:/tmp/libs -r requirements_3.12.8.txt`
        * Replace the path to the temporary folder as appropriate.
2. Run `pip install AiimiInsightEngine-0.4.2-py3-none-any.whl`
   * This will install the Workplace AI library.
3. If you plan to use a GPU to accelerate providers such as sentence transformers:
   1. Uninstall torch with the following command: `pip uninstall torch`
   2. Reinstall torch using the pip command generated by this site: [https://pytorch.org/get-started/locally/](https://pytorch.org/get-started/locally/)
      * For example `pip install torch --index-url https://download.pytorch.org/whl/cu118`
4. In the InsightMaker.Pyton\AIModelService edit run.bat
5. Change the location to match your virtual environment.

## Register the AI Model Service

Edit the main configuration to the service can register itself:

1. Open the `config/config.json` in an editor.
2. **Scheme:** This should remain http.
   * If you plan to use proxy requests through an HTTPS reverse proxy [see our guide to using SSL.](../using-ssl.md)&#x20;
3. **Address:** This should be the IP address or host name of the server. <mark style="color:red;">Do not use localhost.</mark>
4. **Port, Threads , maxRequestHeaderSize, and maxRequestBodySize:** should not need changing at this stage
5. **System secret:** This should contain the Workplace AI system secret.
6. **Skip System Decrypt:** If skipSecretDecrypt is `false` the systemSecret parameter will be treated as encrypted.
7. **Key Vault:** If an Azure KeyVault URL is added system secret and certificate configurations will be treated as Keyvault secret/certificate names. Python will attempt to read them using Azure Default Authentication.
8. **Admin API:** This should point at the Admin API URL.
9. **caCerts & caPassword:** These are the parameters for a certificate authority.
   * They are used to authenticate connections to Elasticsearch.
   * These are optional parameters where required.
10. **Trusted IPs:** This should contain the IP Address of all your user interface servers.

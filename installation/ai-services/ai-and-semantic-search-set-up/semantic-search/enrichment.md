# Enrichment

The textContent needs to be transformed into vectors through an AI enrichment step.

1. Within Steps add an AI Enrichment step.
2. **Select an AI enrichment Service:** From the first drop down select the AI enrichment service you want to use.
3. Select Add Step
4. **AI Enrichment Service:** Select HF Sentence Transformers from the dropdown list.
5. **Model:** Select the Model you want to use from the dropdown list.
6. **Vector:** Select the Vector you want to use from the dropdown list.

_For support configuring an enrichment step_ [see our guide on creating an enrichment pipeline.](https://docs.aiimi.com/aiimi-insight-engine/control-hub/configurations/enrichment-configurations/creating-a-pipeline)

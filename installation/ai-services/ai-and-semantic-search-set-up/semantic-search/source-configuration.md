# Source Configuration

You will need to enable semantic searches on the sources you want them available on.

## **Editing a source**

1. Find the source you want to edit from the source configuration list.
2. Select Edit from the options menu.
3. General Tab > Mapped Vectors - Select the vectors that can be used with this source.

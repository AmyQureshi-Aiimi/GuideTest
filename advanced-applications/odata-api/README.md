# OData API

Create one off or regular reports with value effortlessly. Our OData API connects Aiimi Insight Engine and your 3rd party analytics tools. Use the enriched data from Aiimi Insight Engine to create unique, data-driven visualisations.

Query the data using the configured entity sets and OData standards $functions. The data is identical to how Aiimi Insight Engine would show it, the same data and order.

You can connect this API from your 3rd party tools that accept OData such as Power BI and Tableau.

### Uses for OData

These reports could improve efficiencies, manage risk or inform strategic and operational decisions.

**Data consolidation and migration.**

Understand what documents are stored where, your space needs, and if they are still used. With this insight you can plan and manage your data and storage.

**Risk management.**

Create regular risk reports based on your policies and any legal requirements. This can track your compliance for things like GDPR and help you lower and manage your risk.

**Project management.**

Monitor the progress of a project based on any key metrics and identify speed bumps from one report. This can improve the speed and transparency of reporting for stakeholders.

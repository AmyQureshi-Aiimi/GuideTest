# Metrics

Metrics within Aiimi Insight Engine is a great way to see the details around how it works and is being used. You likely won't need to use the Metrics area everyday but it's a handy tool to have.



### **Volume of Searches**

See how many searches are being performed for certain types of information. This can help you understand what area of the application is most beneficial

<figure><img src="../.gitbook/assets/image (95).png" alt="" width="375"><figcaption></figcaption></figure>

### **Usage By Department**&#x20;

See how many searches are being performed by different departments in the business. This can help you understand who is making the most of the system.



![](<../.gitbook/assets/image (138).png>)

### User Feedback

You can see what users think of the app, and how they rate it. This can help you improve the areas that need help and make the system as valauble as possible.

![](<../.gitbook/assets/image (188).png>)

You can also see the volume of users accessing Aiimi Insight Engine each day, visits to different pages, and the most popular search terms.&#x20;

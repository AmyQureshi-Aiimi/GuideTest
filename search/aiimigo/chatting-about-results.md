# Chatting About Results

When you've performed a search you can select items from your results to talk to Aiimigo about.&#x20;

## Chat About One Item

1. From your result list, hover over the item you want to discuss.
2. Select Ask a Question from the quick actions menu.
   * This will open Aiimigo alongside your results list.
3. Enter your prompt or question in the text box and select Submit Prompt.
   * You can then talk to Aiimigo about it's response, ask it to update it's findings based on more information or ask a completely new question.
4. Aiimigo will search within the selected item for the answer to your prompt.
5. You can then talk to Aiimigo about it's response, ask it to update it's findings based on more information or ask a completely new question.

{% hint style="warning" %}
Selecting a new item from your results list does not change the item Aiimigo is focusing on. To talk about a different item you must select Ask a Question on the new item.
{% endhint %}

### Chat History

Any conversations you have had with Aiimigo can be found in your chat history. This applies for system wide and specific item chats.

1. Find and Select the item you have chatted about previously.
2. Select Ask a Question from the quick actions menu.
   * This will open Aiimigo alongside your results list.
3. Select Recent Prompts within the Aiimigo chat.
4. Select the prompt from list you want to see.
5. You will see the history of that chat and you can continue the conversation.

***

## Chat About Multiple Items

1. From your result list, select the items you want to discuss with Aiimigo.
2. Select Ask a Question from the multi select actions menu.
   * This will open Aiimigo alongside your results list.
3. Enter your prompt or question in the text box and select Submit Prompt.
   * You can then talk to AIimigo about it's response, ask it to update it's findings based on more information or ask a completely new question.&#x20;
4. To clear your chat and start again select clear current prompt from the options menu.

<figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Selecting a new item from your results list does not change the items Aiimigo is focusing on. To talk about a different items you must select the new items and Ask a Question again.
{% endhint %}

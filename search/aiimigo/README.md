# Aiimigo

Aiimigo is an AI helper that breaks down the walls between sources. You can get the answers you need in one place. It uses Large Language Models to understand your request and search for relevant items and perform tasks to help.&#x20;

Aiimigo can get answers to questions, summarise documents, find information and much more. You can ask Aiimigo to find answers based on everything.

{% hint style="info" %}
All AI tools and features, including Aiimigo, are only available if enabled by an administrator.
{% endhint %}

## What It Can Do

{% stepper %}
{% step %}
### Answering Questions

You can ask Aiimigo a question and it will search all of the information available to get you the answer. Whether you have a question about a specific item or when you don't know where to look.
{% endstep %}

{% step %}
### Summarising Information

When you have many documents to review or search through Aiimigo can summaries each into a digestible amount. You can also use it to summaries a group of documents, it is able to talk about common threads or the differences in items
{% endstep %}

{% step %}
### Document Sparring

Aiimigo can review an item in Aiimi Insight Engine. It's like a second pair of eyes that can check your documents. You can have it check for inaccuracies, ensure the information is clear and make suggestions on where to improve the document based on its need.  &#x20;
{% endstep %}

{% step %}
### Charts and Graphs

Aiimigo can make bar, pie, or radar charts from your information. It turns insights into simple, engaging visuals without needing to leave the chat.
{% endstep %}

{% step %}
### Item Relationships

Aiimigo can analyse items and build a relationship map that you can use to explore how items and concepts connect. Selecting a connection will show the evidence behind it and uncover deeper patterns and insights.
{% endstep %}
{% endstepper %}

# Folder Browsing

You can navigate your data by browsing subfolders. You can share information and add it to collections or SAR from a folder. You can browse your folders based on business area or function.&#x20;

1. Select Folder Browsing from the application menu.
2. Select the Folder structure you want to explore.&#x20;
3. Continue to drill down through sub folders to find the information you are looking for.&#x20;
4.  Archived data keeps its original folder structure so you can find data in a familiar way.

# Relationship Map

Visualise the relationships and connections between documents and data. You can see how names connect to phrases, locations and concepts. This Removes the need to dive through individual results to find commonalities.

<figure><img src="../../../.gitbook/assets/image (165).png" alt="" width="563"><figcaption></figcaption></figure>

## Accessing the Relationship Map

After performing a search, if any of your results have connections the relationship map lens will be available.&#x20;

1. Select Relationship Map from the Lenses menu.

![](<../../../.gitbook/assets/image (171).png>)

<details>

<summary>Accessible Relationship Map</summary>

You can use keyboard navigations to reach an accessible table of the relationship map.

1. Use the tab key to navigate past Min Results.
2. Select Show as Table option to open a table below the diagram.
   1. First column: all entities and the entities they relate to.&#x20;
   2. Second column: the links to view the connected results.

</details>

## Using the Relationship Map

<details>

<summary>Connected Entities</summary>

You can see every entity within your result and how they are all connected.

1. Select a label box to highlight the other entities it is connected to.
   * The line between each box shows the number of results that connect them.
   * Labels types have different colours within the box and an icon to distinguish them.

![](<../../../.gitbook/assets/image (273).png>)

</details>

<details>

<summary>Common Items</summary>

You can easily see the items connecting entities and view them all in a list. This allows you to quickly and easily find connected items.

1. Select the number or the line connecting two boxes.&#x20;
2. A relationship panel will open with the number of results connecting the two entities.&#x20;
3. Select 'View all related results' to see all the related results in a list.

<img src="../../../.gitbook/assets/image (158).png" alt="" data-size="original">

</details>

<details>

<summary>Minimum Results</summary>

You can choose the number of related results that must exist for a connection to appear in the diagram. For example; if the Min Result is set to 5, any entities with 5 or more items connecting them will appear.&#x20;

1. Select the Min Result field.&#x20;
2. Enter the minimum number of results between a connection you want.
   * Increasing this number will give you fewer results with stronger connections.\
     Reducing this number will give you more results with weaker connections.
3. When you change the number the diagram will automatically update.

<img src="../../../.gitbook/assets/image (156).png" alt="" data-size="original">

</details>

<details>

<summary>Relationship Type</summary>

Find different types of connections using the Relationship Type dropdown. Each relationship type will look for specific entities.

1. Select the Relationship Type dropdown.&#x20;
2. Choose a type from the dropdown menu.
   * You can change your relationship type at any time and it will update your results.
   * PCI relationship types may consist of entities like Card Numbers, CVVs, and Bank names.
   * Organisation types may consist of organisation names and locations.&#x20;

<img src="../../../.gitbook/assets/image (107).png" alt="" data-size="original">

</details>

<details>

<summary>Custom Relationship Types</summary>

If you can't find the connection you are looking for you can create your own. Any custom types can not be saved for future use.&#x20;

1. Select Relationship Type.&#x20;
2. Select Custom Selection from the menu.
3. In the next dropdown, select the attributes you want to find a connection for.&#x20;
4. Select Apply Selection.&#x20;

<img src="../../../.gitbook/assets/image (226).png" alt="" data-size="original">

</details>

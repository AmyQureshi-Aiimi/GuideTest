# Quick Actions

There are a number of quick actions that can be performed from a result. This includes sharing items, marking them as useful or sensitive.&#x20;

<details>

<summary>Share an Item</summary>

Share the items you find within Workplace AI with other users. You can share items from your results list or the preview.

1. Select the Option menu from the quick action bar or preview navigation.
2. Select Share Item from the menu. This will open a new modal.

<img src="../../.gitbook/assets/image (260).png" alt="" data-size="original">

3. **Share With** - Start typing the name of the user or group you want to share it with.
4. Select the user or group from the list you want to share this with.
5. **Message** - You can add notes or comments that are sent in the email with the link.&#x20;
6. Select Share

<img src="../../.gitbook/assets/image (261).png" alt="" data-size="original">

</details>

<details>

<summary>Mark as Useful</summary>

Items within Workplace AI can be marked as useful by any user. This can make it easier for others to find what they are looking for and the most relevant information. It can help people across the business deliver more informed decision-making.&#x20;

1. Hover over an item to show the quick actions menu.
   * _When you tab into a result card the actions menu will also become available._
2. Next to the Mark as Useful button (Thumbs Up) there will be a count of everyone who found this useful.&#x20;
3. Select Mark as Useful to add your approval to a document.
   * Select mark as useful again to remove your mark, this will reduce the count.

<img src="../../.gitbook/assets/image (50).png" alt="" data-size="original">

</details>

<details>

<summary>Mark as Sensitive</summary>

If you find a document that you believe should not be visible to others due to sensitive content you can mark it as sensitive. This will stop a file from being returned in all searches going forward.\
\- _All items marked as sensitive are reviewed by an administrator before the file is hidden._

If you think a file has been marked as sensitive incorrectly contact your admin to change this.

1. Hover over an item to show your quick actions menu.
   * _When you tab into a result card the actions menu will also become available._
2. Select the Option menu at the end of this list.
3. Select Mark as sensitive from the dropdown list.
   * _This will open a sensitive file pop up._
4. Enter why you think the item should be sensitive within the text box.
5. Select Save.
   * This will send a request to an admin to review and approve. Once approved the file will be removed from future searches.

</details>

# Bulk Search

When building a legal case, right to be forgotten or something similar you need to regularly run lots of searches. With Bulk Search you can create and group multiple searches to run on a schedule. It's great for running lots of searches about the same topic or within the same data model. It reduces the number of manual searches and improves consistency and data discoverability.&#x20;

There is no limit to the number of searches you can add to a bulk search. The only limitation is the number of results that can be returned. This is limited to 10,000 results.&#x20;

## **Finding Your Bulk Searches**

Find your existing bulk searches and create a new one from My Searches.

1. Select Account from the top navigation.
2. Select My Searches from the account menu.
3. Select Saved Searches then Bulk Searches.

{% hint style="info" %}
If you can not see bulk searches it is likely disabled. Contact your Aiimi Insight Engine administrator to enable this feature.
{% endhint %}

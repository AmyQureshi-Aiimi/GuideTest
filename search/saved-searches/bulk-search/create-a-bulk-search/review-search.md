# Review Search

Choose the sources each search/row of your file will be searched within. You can choose any number of sources from those available to you within Workplace AI.

{% hint style="info" %}
By default the sources selected are your enabled sources in search settings.
{% endhint %}

1. Select the sources to search from the Source filter dropdown.
   * The list will contain all the sources you have access to and you can add or remove them from this list as needed.
   * If you change your selection you can reapply the original sources by selecting Apply Default Sources.
2. Repeat this step for each search.
3. Select [Continue to Notifications.](notifications.md)

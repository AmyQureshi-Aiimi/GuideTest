# Create a Bulk Search

{% hint style="info" %}
You will need a CSV file containing all of the searches you want to run in the bulk search. Use the [guide for creating a Bulk Search template](../bulk-search-template.md) to make this.
{% endhint %}

1. Select Account from the top navigation.
2. Select My Searches from the account menu.
3. Select Saved Searches then Bulk Searches.
4. If you can not see bulk searches it may be that your administrator has not enabled this feature.
5. Select New Bulk Search
6. This will take you to a new Bulk Search, [Search Details](search-details.md) page.

### Editing a bulk search

Before processing bulk searched the job gets all the CSVs it needs to process. If you edit your settings or CSV while the job is running these changes will not be applied until the next time the search is performed.&#x20;

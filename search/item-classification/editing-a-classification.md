# Editing a Classification

Certain subject matter experts can manage the classifications applied to an item. They're able to change incorrect classifications. This helps ensure the information everyone can see is accurate and helpful.

If you have access to manage classifications you can access this in two ways.

1. From the items quick actions menu, select Manage Classification.
2. Within the Classifications tab of Result Details select Manage.

Both will open a Manage Classifications modal to change the classification of this item.&#x20;

1. **Classifications:** Select the classification for this item from the dropdown.
   * You will only see the classifications you have access to manage in this list.
2. **Class:** Select the class this item should be assigned from the dropdown list.
   * You will only see classes from the selected classification.
3. **Comment:** Leave a comment about why this item needed changing.&#x20;
   * This could help classification in the future and be used as part of an audit.
4. Select Update
